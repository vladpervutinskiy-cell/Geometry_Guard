Geometry Guard
Мини-приложение на Python: не даёт открыть выбранную программу без пароля.
ОБРАТИТЕ ВНИМАНИЕ!Программа откроется в трее, а не сразу появится в окне. Поэтому вам нужно в правом нижнем углу, рядом с вайфай, выбрать стрелочку вверх. Кликнуть на нее и выбрать приложение(значок с щитом) !
При первом запуске приложение просит:

выбрать .exe, который нужно блокировать (например, GeometryDash.exe);
придумать свой пароль.
Дальше защита включается сразу с сохранёнными настройками, работает в фоне и следит за выбранной программой. Если открыть выбранную программу, она мгновенно закрывается, а на экране появляется окно с запросом пароля. После верного пароля программа запускается заново.

При каждом запуске Windows покажет запрос прав администратора (UAC) — без них защита не сможет закрывать чужие процессы. После настройки приложение живёт в области уведомлений (возле часов), а не в панели задач.

Сторонние библиотеки не нужны: только Python 3.8+ для Windows (tkinter входит в стандартную установку с python.org).

Первый запуск
Установите Python с python.org, при установке отметьте Add Python to PATH.
Дважды кликните start_guard.bat (или создайте ярлык на него).
Программа откроется в трее, а не сразу появится в окне. Поэтому вам нужно в правом нижнем углу, рядом с вайфай, выбрать стрелочку вверх. Кликнуть на нее и выбрать приложение(значок с щитом) 
В открывшемся окне нажмите «Обзор…» и укажите программу, которую нужно закрывать (например, ...\steamapps\common\Geometry Dash\GeometryDash.exe). Путь можно и просто вставить в поле вручную.
Введите пароль дважды (минимум 4 символа) и нажмите «Включить защиту».
Настройки сохраняются, и при следующих запусках окно выбора больше не появляется — защита стартует сразу, уже в фоне.

Фоновый режим и значок в трее
После сохранения настроек окно можно закрыть крестиком — приложение не завершится, а свернётся в область уведомлений (возле часов).
Кнопка «Свернуть в фон» делает то же самое.
Кнопка «Остановить защиту» (нужен пароль) только выключает блокировку — приложение остаётся открытым и висит в трее. На главном экране появляется надпись «Защита остановлена» и кнопка «Включить защиту».
Кнопка «Выход» (нужен пароль) полностью закрывает приложение вместе со сторожем. Это единственный штатный способ завершить его совсем.
Значок в трее: двойной клик — открыть окно, правый клик — меню «Открыть», «Настройки», «Остановить/Включить защиту», «Выход».
Если процесс Geometry Guard завершить принудительно (например, из диспетчера задач), отдельный сторожевой процесс запустит его снова. Исключение — штатный «Выход»: тогда сторож тоже завершается и не мешает.
При запуске выбранной программы окно само появится поверх остальных, чтобы запросить пароль, даже если было свёрнуто в трей.
Если нужен автозапуск
Приложение само просит права администратора, поэтому при входе в Windows появится запрос UAC. Чтобы защита стартовала автоматически:

Нажмите Win+R, введите shell:startup и нажмите Enter.
Скопируйте в открывшуюся папку ярлык на start_guard.bat.
Если нужен запуск совсем без запроса UAC, создайте задачу в Планировщике заданий Windows с галочкой «Выполнять с наивысшими правами» и действием start_guard.bat. Это уже настройка Windows, а не самого приложения.

Для диагностики можно запустить py geometry_guard.py — приложение попросит UAC и продолжит работу; сообщения об ошибках смотрите в окне приложения.

Как это работает
Приложение раз в 0,4 секунды просматривает список процессов Windows и ищет процесс с выбранным именем .exe.
Найденный процесс мгновенно завершается, а поверх остальных окон открывается диалог с паролем (поле со скрытыми символами).
Неверный пароль — вибрация окна и сообщение; после 3 попыток ввод блокируется на 10 секунд.
Верный пароль — программа запускается снова, и в течение 60 секунд повторные запуски не требуют пароля (чтобы успели стартовать все процессы программы).
Приложение считает, сколько запусков было заблокировано.
Рядом работает маленький сторожевой процесс. Он ждёт завершения основного процесса и, если тот закрылся не через «Выход», запускает его снова. Так защита возвращается в фон даже после принудительного завершения.
Когда вы нажимаете «Остановить защиту», блокировка и сторож выключаются, но само приложение продолжает работать. «Включить защиту» запускает их заново.
Настройки находятся в начале geometry_guard.py:

POLL_INTERVAL = 0.4        # период проверки процессов
UNLOCK_SECONDS = 60        # «окно» после ввода пароля
MAX_ATTEMPTS = 3           # попыток до паузы
LOCKOUT_SECONDS = 10       # длительность паузы
MIN_PASSWORD_LENGTH = 4    # минимальная длина пароля
WATCHDOG_MAX_RESTARTS = 5  # перезапусков за 10 минут (защита от цикла падений)
Сменить приложение или пароль
В главном окне нажмите «Настройки» и введите текущий пароль (кнопка «Продолжить»). Откроется экран настроек:

сверху видно, что блокируется сейчас;
путь к .exe можно изменить: нажмите «Обзор…» и выберите новый файл либо вставьте путь в поле вручную (кавычки и переменные вида %ProgramFiles% допускаются). Под полем сразу показывается, какой процесс будет блокироваться;
пароль: выберите «Оставить текущий пароль» (поля заблокированы) или «Задать новый пароль» и введите его дважды.
После «Сохранить» защита сразу перезапускается с новыми настройками, в главном окне появляется надпись «Настройки сохранены» и новое имя программы. Кнопка «Отмена» возвращает к защите без изменений.

Если перед входом в настройки защита была остановлена, после сохранения она останется остановленной — включите её кнопкой «Включить защиту».

Где хранятся настройки
%APPDATA%\GeometryGuard\config.json
Там лежат путь и имя выбранной программы, а пароль — только в виде случайной соли (salt) и SHA-256 хеша (password_hash). Открытым текстом пароль нигде не хранится.

Забыли пароль? Удалите этот файл — при следующем запуске приложение снова попросит выбрать программу и задать пароль. (Это же является способом обойти защиту, см. ограничения ниже.)

Сборка в один .exe (необязательно)
Чтобы не зависеть от установленного Python и спрятать исходный код:

py -m pip install pyinstaller
py -m PyInstaller --noconsole --onefile --name GeometryGuard geometry_guard.py
Готовый файл появится в dist\GeometryGuard.exe. Его можно запускать или положить ярлык в автозагрузку вместо .bat.

Важные ограничения
Программа всегда запускается с правами администратора и просит подтверждение UAC. Если нажать «Нет», защита не включится — это сделано специально, иначе она не смогла бы закрывать чужие процессы.
Сторожевой процесс перезапускает защиту после обычного завершения, но не является неубиваемым: если завершить сразу оба процесса (например, «завершить дерево процессов» в диспетчере задач), защита останется выключенной. Также её можно обойти, удалив файл настроек, переименовав программу или изменив скрипт. Это «домашняя» защита от случайного запуска, а не полноценный родительский контроль.
«Остановить защиту» с паролем выключает блокировку и сторожа, но приложение продолжает работать. Чтобы закрыть его совсем, используйте отдельную кнопку «Выход» — тоже с паролем.
Программа закрывается принудительно — несохранённый прогресс может потеряться (Geometry Dash сохраняет прогресс автоматически).
Нельзя выбрать в качестве цели сам Python (python.exe/pythonw.exe) — приложение не даст заблокировать само себя.
